Autonomous Robot

Purpose
This project focuses on building an autonomous robot which follows objects and is capable of sensing objects and avoiding them 

Demo Video
https://youtube.com/shorts/ZuDGWGZLdUQ?feature=share

Materials
- Arduino
- Breadboard
- Pack of wheels (2)
- IR Receiver (2)
- Ultrasonic Sensor
- Battery Pack
- DC Motor Pack (2)
- LEDs
- Electrical Tape
- Universal Wheel

How to Install and Upload
- Open Arduino IDE and create new sketch
- Paste the code into blank sketch window and save
- Go to Tools - Board, the select your Arduino board (Arduino Uno in my case)
- Plug Arduino board into computer
- Go to Tools - Port - Select port that shows your Arduino
- Click the check mark and wait until done compiling
- Upload the code
